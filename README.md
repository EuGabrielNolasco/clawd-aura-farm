# Clawd Aura Farm 😎

Um mini jogo de clique em que o Clawd, o mascote do Claude Code, faz o **six seven** sem parar enquanto você farma aura.

## Como jogar

Abra o `index.html` no navegador e clique no Clawd ou no botão **FARMAR AURA**.

- Cada clique dá +67 de aura, multiplicado por 5 a cada nível
- 10% dos cliques saem crítico (10×)
- O Clawd também farma sozinho
- A aura fica salva no seu navegador (localStorage)
